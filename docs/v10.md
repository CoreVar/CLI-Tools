# CLI Tools v10

CLI Tools v10 targets `net8.0` and `net10.0`. Applications can stay on .NET 8 while adopting the same API shipped for .NET 10. Future major releases follow the even-numbered .NET LTS line; patches remain compatible with every target framework carried by that major.

## A small command with production features

```csharp
await CliApp.RunAsync(app =>
{
    app.EnvironmentPrefix("ACME_")
       .Version("10.0.0")
       .Use(async (context, next) =>
       {
           var started = Stopwatch.GetTimestamp();
           await next(context);
           await context.Console.WriteErrorLine($"completed in {Stopwatch.GetElapsedTime(started)}");
       })
       .Command("deploy", command =>
       {
           var environment = command.Argument<string>("environment")
               .Complete("dev", "stage", "prod")
               .Must(value => value is "dev" or "stage" or "prod", "Unknown environment.");

           var replicas = command.Option<int>("--replicas")
               .WithAlias("-r")
               .FromEnvironment()
               .FromConfiguration("Deploy:Replicas")
               .Default(1)
               .Range(1, 100);

           command.OnExecute(context => DeployAsync(
               context.GetArgument(environment),
               context.GetOption(replicas),
               context.CancellationToken));
       });
});
```

Command-line values win over environment values, which win over configuration and then defaults. Use `Global()` for an option inherited by subcommands, `Variadic()` for the final argument, and `Validate(...)` for cross-value rules.

## Components

Component attributes expose the same metadata without handwritten registration:

```csharp
[CommandName("deploy", Aliases = ["ship"])]
public sealed class DeployComponent : CommandLineComponent
{
    [CommandArgument("files", Variadic = true)]
    public string[] Files { get; set; } = [];

    [CommandOption("--environment", EnvironmentVariable = "ACME_ENV",
        ConfigurationKey = "Deploy:Environment", Completions = ["dev", "prod"])]
    public string Environment { get; set; } = "dev";

    public Task ExecuteAsync() => Task.CompletedTask;
}
```

Commands and options can also be hidden or marked deprecated. The source generator emits direct binding code and requires no runtime command discovery.

## Completion and documentation

Users can run `mytool completion bash`, `zsh`, `fish`, or `powershell`. Build tooling can emit the same scripts with `app.GenerateCompletion(shell)`. `app.GenerateMarkdown()` creates a reference from the exact command tree used at runtime.

## Interactive and structured output

Handlers can call `context.PromptAsync(...)` and `context.ConfirmAsync(...)`. JSON helpers accept source-generated `JsonTypeInfo<T>`, keeping the path compatible with trimming and Native AOT:

```csharp
await context.WriteJsonAsync(result, AppJsonContext.Default.DeployResult);
await context.WriteJsonLinesAsync(results, AppJsonContext.Default.DeployResult);
```

REPL mode includes bounded in-memory history: `history` lists prior commands and `!!` repeats the latest command. Shell-completion generation is available from the REPL exactly as it is in one-shot mode.

### Blazor terminal interaction

`CommandLineConsole` behaves like a keyboard-first terminal rather than a regular form control. It supports Up/Down history, metadata-driven Tab completion, Ctrl+C interruption, Ctrl+L clear screen, Ctrl+U clear line, Ctrl+K delete-to-end, Ctrl+W delete-word, Escape, click-to-focus, selection/copy, smart scroll following, ANSI foreground/bold colors, carriage-return progress updates, bounded scrollback, and responsive/mobile layouts.

Set `HistoryKey` to retain non-secret command history in browser local storage across refreshes. The component reports character-cell dimensions through `IBrowserTerminal.Size` and `SizeChanged`; handlers can call `ReadSecretAsync` to switch the browser input to password mode without echoing or persisting its value. These browser capabilities remain separate from process launching: external executables run only in the trusted server host, never in WebAssembly or as an arbitrary browser shell.

```razor
<CommandLineConsole CliApp="app"
                    AutoFocus="true"
                    HistoryLimit="200"
                    MaxLines="5000"
                    HistoryKey="operations"
                    AriaLabel="Operations terminal" />
```

When output is selected, Ctrl+C retains the browser's normal copy behavior. Otherwise it emits `^C` and cancels the executing handler through `CommandExecutionContext.CancellationToken`.

## Signature-driven components

Public `Execute`/`ExecuteAsync` parameters are source-generated directly into arguments and options. Unannotated parameters become positional arguments, `[CommandOption]` marks options, and `CancellationToken` is injected automatically:

```csharp
public Task ExecuteAsync(
    string environment,
    [CommandOption("--force")] bool force,
    CancellationToken cancellationToken) => DeployAsync(environment, force, cancellationToken);
```

This uses no runtime reflection and remains Native AOT compatible. Property-backed components continue to work unchanged.

## Testing

Use `await builder.TestAsync("deploy prod --replicas 3")` to execute the real host with an in-memory console and inspect `ExitCode`, `Output`, and `Error`. Response files (`@args.txt`), `--option=value`, repeated options, compact flags (`-abc`), and the `--` end-of-options marker use the same parser in tests and production.
